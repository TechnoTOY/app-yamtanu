# Marque Yamtaanu Miel - ERP de Traçabilité & Gestion

Ce dépôt contient l'application web de gestion et de traçabilité pour la marque **Yamtaanu Miel**. 
C'est un outil ERP complet conçu pour le suivi apicole, l'atelier de brassage de jus et de thés, l'impression de fiches d'origine de qualité A4 avec codes QR dynamiques, et le suivi financier (ventes, commandes, créances).

## 🚀 Fonctionnalités principales

- **Tableau de bord ERP** : Indicateurs de performance en temps réel (chiffre d'affaires, ventes, créances, état des stocks).
- **Atelier Apiculture** : Saisie des récoltes, suivi des ruches, état de santé, contrôles d'humidité, et traçabilité complète des lots de miel.
- **Atelier Jus & Thés** : Gestion des brassages de jus de fruits et des lots d'herboristerie.
- **Génération & Impression de Codes QR** :
  - Création de fiches de traçabilité professionnelles au format A4 prêtes à l'impression.
  - Codes QR de traçabilité dynamiques pour les pots de miel, pointant vers les détails du certificat d'origine.
- **Configuration Personnalisée** : Gestion dynamique en temps réel des listes déroulantes (artisans, localités, saveurs, clients, transporteurs).
- **Sécurité et Authentification** : Portail de connexion pour restreindre l'accès à l'administration ERP, tout en laissant la consultation de traçabilité publique pour les clients scannant les codes QR.

## 🛠️ Technologies utilisées

- **React 18** & **TypeScript**
- **Vite** (Framework de build ultra-rapide)
- **Tailwind CSS** (Design moderne et responsive)
- **Lucide React** (Bibliothèque d'icônes)
- **Framer Motion** (Animations fluides)

## 📦 Installation locale

1. **Cloner le projet** :
   ```bash
   git clone https://github.com/TechnoTOY/marque-yamtaanu-miel.git
   cd marque-yamtaanu-miel
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

4. **Construire pour la production** :
   ```bash
   npm run build
   ```
